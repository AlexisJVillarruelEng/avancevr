# avancevr

Proyecto de Unity **6.5 (6000.5.9f1)**, basado en la plantilla Universal Render Pipeline (URP).

## Abrir el proyecto

1. Clona este repositorio o descarga el ZIP desde **Code**.
2. En Unity Hub, selecciona **Add → Add project from disk** y elige la carpeta del repositorio.
3. Ábrelo con Unity **6000.5.9f1** y espera a que se descarguen los paquetes y se importen los recursos.
4. Abre `Assets/Scenes/SampleScene.unity`.

## Proponer cambios

1. Crea un **fork** de este repositorio en tu cuenta de GitHub.
2. Crea una rama, realiza tus cambios y súbelos a tu fork.
3. Abre un **pull request** hacia la rama `main` de este repositorio para que el propietario lo revise.

El repositorio es público. Para subir cambios directamente se necesita una invitación del propietario como colaborador.

## Archivos del proyecto

Se incluyen `Assets`, `Packages` y `ProjectSettings`, junto con sus archivos `.meta`. Las carpetas temporales de Unity (`Library`, `Temp`, `Logs` y `UserSettings`) están excluidas y se regeneran localmente.
