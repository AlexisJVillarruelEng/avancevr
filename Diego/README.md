
# Minijuego Recolector AR

Responsable: Diego

## Descripcion
Minijuego tipo Pac-Man desarrollado en C#,
preparado para su futura integracion en Unity/Vuforia.

## Funcionalidades
- Movimiento del jugador
- Colisiones con obstaculos
- Recoleccion de monedas
- Sistema de puntuacion
- Cronometro
- Victoria y derrota
- Reinicio de partida
- Prototipo jugable en consola
- Pruebas automatizadas

## Tecnologias
C#, .NET 10, xUnit y VS Code.

## Ejecucion
dotnet run --project Diego/Recolector.Dem

## Pruebas
dotnet test Diego/Recolector.Tests

## Pendiente de integracion
